# WOYO Match

Site web mobile-first (installable sur téléphone) qui met en relation les **propriétaires de voitures** et les **chauffeurs VTC** à Abidjan, avec des contrats durables pour réduire la précarité des chauffeurs et le turn-over côté propriétaires.

## Mettre le site en ligne (gratuit, 3 clics)
1. Dans ce dépôt : **Settings > Pages**.
2. Sous « Build and deployment », Source : **Deploy from a branch**.
3. Branche : **main**, dossier : **/ (root)**, puis **Save**.
4. Après 1 à 2 minutes, l'adresse du site s'affiche en haut de cette même page Pages (du type `https://alain229....github.io/WoyoMatch/`).

## Contenu
- `index.html` : le site (prototype avec données de démonstration).
- `manifest.webmanifest`, `icon.svg`, `sw.js` : rendent le site installable sur le téléphone comme une application.
- `cahier-des-charges.md` : cahier des charges du MVP.

## Feuille de route
1. Prototype (fait) : offres, candidats, compatibilité, publication de voiture.
2. Comptes et base de données (inscription par SMS, profils réels).
3. Vérification CNI/permis, contrat numérique, évaluations croisées.
4. Paiement mobile money (Orange, MTN, Moov, Wave) et forfaits propriétaires.
